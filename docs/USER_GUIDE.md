# GEETA AI IDE User Guide

## Overview

GEETA AI IDE is a desktop development environment with AI-assisted coding, search, diagnostics, Git integration, and workspace tooling.

## Features

- Edit and save files
- Use search, quick open, and symbol search
- Review diagnostics and chat with the built-in AI assistant
- Work with Git, settings, and workspace-aware tools

## Getting Started

1. Install Python dependencies from requirements.txt
2. Run main.py to launch the IDE
3. Open a workspace and start coding

## Troubleshooting

- If tests fail, run pytest -q from the project root
- For packaging, use the build scripts in the packaging folder when available
